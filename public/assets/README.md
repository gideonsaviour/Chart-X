# Chat-X public assets

Place the user-approved, unchanged file `chat-x-neon-skyline-splash.png` in this directory. The app references it as `/assets/chat-x-neon-skyline-splash.png` and displays it as the initial full-screen image, without cropping, overlays or restyling. The splash automatically advances after approximately 3.2 seconds and also responds to a tap.

Do not replace the screenshot with recreated artwork.
