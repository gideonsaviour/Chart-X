# Chart-X 💬

Chart-X — social networking, messaging, communities, marketplace and trading (frontend demo).

## Features
- ⚡ Real-time messaging
- 👥 Group chats
- 📞 Voice & video calls
- 📎 Media sharing
- 🔐 End-to-end encryption
- 🟢 Online/offline status

## Tech Stack
- React 18
- Vite
- Tailwind CSS
- Lucide Icons

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
